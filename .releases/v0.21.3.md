**Version.** Last release `0.21.2`; last version in General `0.21.2`. Since `0.21.2`: new features and fixes, nothing breaking. **Jump in General (`REL3`).** none.
**Resolves from General alone (`REL4`).** ✅.
**Versions applied.** ct-agents `v0.5.0` (this recipe), ct-conventions `v0.15.0`, CTActions `dc60661` (the release tool).

### What changes since `0.21.2`

- New: the Hamiltonians of a model, `pseudo_hamiltonian` and `hamiltonian`, with the cost multiplier `p0`; the constraints by label (path constraints, state boxes, control boxes), with the multipliers as an argument or in feedback form, in the sign convention of the duals of a solution; batched states with constraints; two labels of the same box component are rejected (#538, #532). `CTModels.Models.is_unnamed_label` (#534).
- Fixed: the plot rows of unnamed constraints no longer show the generated label (#526); a solution of a model with unnamed constraints written by CTParser can be imported again; the messages of `build_solution` no longer show the generated label.
- Improved: the constraint accessors return named functors (`SubPathConstraint`, `SubBoundaryConstraint`, `CompositeConstraint`), not anonymous closures (#533, #535).
- Dependencies: the compat of `CTBase` moves to `0.30.15`, the release that provides the constrained Hamiltonians; `ForwardDiff` is a new test dependency.
- Documentation: the page "Hamiltonians"; the pin of ct-conventions v0.15.0 (#537).
- Breaking: none (the `[Unreleased]` note of `BREAKING.md`, on the named functors, becomes `Non-breaking note (0.21.3)`).
- Not in `[Unreleased]` yet, added by the release PR: none. The candidates listed by `facts` are one formatter run (#539), the compat bump, and two bug-fix wordings, all covered.
- Open PRs, not in this release: #489 CompatHelper: bump compat for JET in [extras] to 0.13 (draft).
